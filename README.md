# tfg-estaciones-esqui
TFG Business Analytics sobre saturación y recomendaciones en estaciones de esquí


## Nota sobre los datos

El procesamiento se ha realizado en Google Colab.

El repositorio incluye:
- datos originales seleccionados (`data_raw/`)
- datos procesados (`data_processed/`)
- datasets finales utilizados en el análisis (`data_final/`)
- notebooks con el proceso completo (`notebooks/`)
